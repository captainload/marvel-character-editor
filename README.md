# Marvel Super Heroes (FASERIP) Character Editor & Generator

🎮 **Live Web Application**: [https://captainload.github.io/marvel-character-editor/](https://captainload.github.io/marvel-character-editor/)

A comprehensive web-based character creation, management, and game-aid tool for the classic **Marvel Super Heroes (MSH) Advanced Game (TSR)** system (FASERIP).

## Features
- **FASERIP Ability & Resource Tracking**: Full interactive character sheet with real-time Health, Karma, Resource FEAT calculations, and dice roller integration.
- **Universal Table Engine**: Complete lookup and dice rolling mechanics with Column Shift modifiers, color outcome thresholds (White, Green, Yellow, Red), and pre-roll Karma allocation.
- **Powers, Talents & Forms Database**: Extensive TSR database with power stunt management, exceptional rolls, power slot calculations, and multiple visual themes (Slate, Manilla, Aqua).
- **Rulebook Equipment Store**: TSR Player's Book & Weapons Locker equipment catalog with civilian, military, black market, and S.H.I.E.L.D. clearance access filters, rank abbreviations, and persistent stats popover tooltips.
- **TSR Resource Procurement Evaluator**: Evaluates resource feat difficulties, automatic acquisition thresholds, and black market markups according to TSR Advanced Player's Book rules.
- **Machines of Doom Invention Lab**: Complete 3-phase invention engineering suite (Blueprint Design, Resource Procurement, Assembly & Construction) with ability boosts, limits, reverse engineering, and known schematics archive.
- **Touch-Friendly & Accessibility Support**: Configurable touch target sizing and high-contrast color palettes.

## Tech Stack
- Pure Vanilla JavaScript (ES6+), HTML5, CSS3.
- Zero build tools or external runtime dependencies required; runs directly in any modern web browser.
