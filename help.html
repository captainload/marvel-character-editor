🌟 1. System Overview & Architecture

Overview

The Marvel Super Heroes Character Editor is a dedicated tabletop RPG workstation engineered specifically for TSR's classic Marvel Super Heroes Roleplaying Game (Advanced and Basic sets) and the community-standard Classic Marvel Forever (CMF) rules modifications.

The application runs entirely within any modern web browser with zero external framework dependencies. All calculations, state transitions, dice rolls, and equipment catalogs operate 100% locally on your machine, ensuring full offline capability, zero latency, and persistent local storage.

Key Design Objective: Provide a unified digital workspace that honors the nostalgic 1980s TSR FASERIP rulebooks while equipping modern Game Masters and players with rapid point-buy budgets, automated Universal Action Table resolution, invention crafting, and clean printable character sheets.

⚖️ 2. Vanilla TSR MSHRPG vs. Classic Marvel Forever (CMF)

Rules Comparison

The program provides comprehensive, first-class support for both Vanilla TSR MSHRPG (canonical 1986 Advanced Set / 1984 Basic Set) and Classic Marvel Forever (CMF). You can switch between these modes seamlessly at any time via File / Options ▾ → Preferences & Options or directly from the Rules Cheat Sheet.

Side-by-Side System Comparison

Feature Vanilla TSR Rulebooks (1986) Classic Marvel Forever (CMF)
Rank Progression 18 Canonical Ranks: Shift 0 up to Beyond 22 Expanded Ranks: Adds Fantastic (35), Spectacular (45), Sensational (60), Awesome (90)
Universal Action Table 4-Color Matrix: White (Failure), Green (Standard), Yellow (Remarkable), Red (Spectacular) 5-Color Matrix: Adds Dark Blue Fumble (01-10 down to 01-01) for critical weapon/power malfunctions
Character Creation Random dice generation or fixed archetype templates Flexible Point-Buy: Tier budgets (400, 600, 800, 1000, 1200, 1500 CP) with point-by-point purchasing
Ground Movement 15 Rank brackets 21 Rank brackets with precise miles-per-hour and areas-per-round speed benchmarks
Air / Flight Movement 17 Rank brackets 21 Rank brackets spanning Mach speeds, orbital velocities, and sub-light flight
Material Strengths 13 Canonical materials (Cloth up to Adamantium) 19 Expanded materials (adds Hard Wood, Super-Heavy Steel, Crystallized Adamantium, etc.)
Tactical Area Division Standard 132-foot areas Supports Standard (132 ft), Quadrant (33 ft), Six Subareas (22 ft), and Eight Subareas (16.5 ft)
📘 Vanilla TSR Strengths Canonical
  • Pure 1986 Advanced Set Player's Book & Judge's Book rules parity.
  • Original 4-color threshold bands for players wanting authentic retro table rolls.
  • Original 13-grade material strength chart.
  • Standard 15/17 movement speed steps.
⚡ CMF Enhanced Strengths Community Standard
  • Bridges large power gaps between Remarkable (30) and Incredible (40), and Amazing (50) and Monstrous (75).
  • Dark Blue Fumbles introduce high-stakes blunder and weapon jam drama.
  • Precise point-buy balance prevents power discrepancies in campaign play.
  • 19-material chart covers everyday building materials and cosmic shielding.

How to Switch Rulesets

  1. Click 📁 File / Options ▾ in the top header and select ⚙️ Preferences & Options...
  2. Under Universal Action Table Mode, toggle between:
    • Modified CMF (22 Ranks - Default)
    • Standard TSR (18 Ranks)
  3. Click Save & Close. The dice roller, Universal Action Table matrix, combat maneuvers, and cheat sheet instantly re-render according to your selection.

💰 3. CMF Point-Buy Engine & Budget Accounting

Character Creation

The editor features an interactive, automated Classic Marvel Forever Point-Buy Engine. Rather than relying on swingy random dice rolls, players build heroes according to balanced Character Point (CP) budgets.

Standard CP Budget Tiers

  • 400 CP — Street-Level / City Defender: Vigilantes, martial artists, and neighborhood heroes (e.g., Daredevil, Luke Cage, Spider-Man).
  • 600 CP — Experienced Super Hero: Seasoned mutants and national champions (e.g., Captain America, Wolverine, Cyclops).
  • 800 CP — Major Team Member: Frontline powerhouse heroes (e.g., Iron Man, Storm, Colossus).
  • 1000 CP — Heavyweight / World Class: Elite Avengers and godlike champions (e.g., Thor, Hulk, Silver Surfer).
  • 1200 / 1500 CP — Cosmic / Herald: Cosmic guardians and heralds of the universe.
  • Custom CP: Enter any custom budget for homebrew campaigns or one-shot adventures.

Cost Accounting Formula

Category Point-Buy Cost Formula Notes & Rulebook Citations
Primary Abilities (FASERIP) 1 CP per Rank Number Feeble (2) = 2 CP, Good (10) = 10 CP, Excellent (20) = 20 CP, Remarkable (30) = 30 CP, Amazing (50) = 50 CP.
Secondary Vitals (Health & Karma) 0 CP (Derived Automatically) Health = Fighting + Agility + Strength + Endurance.
Karma = Reason + Intuition + Psyche.
Standard Superpowers 10 CP Base + Rank Number CP e.g., Body Armor at Remarkable (30) costs 10 Base + 30 Rank = 40 CP.
Starred (Heavyweight) Powers 20 CP Base + 2x Rank Number CP Per TSR Player's Book p. 19 & UPB p. 16–19, heavyweight powers (Alter Ego, Energy Mastery, Power Simulation, etc.) count as two powers and cost 2x.
Superior Option Tax (House Rule) Toggleable in Preferences Optional surcharge for superior power choices. When disabled by the GM, superior options incur zero penalty.
Talents 10 CP Standard / 20 CP Starred (*) Standard talents cost 10 CP. Heavyweight professional or combat masteries cost 20 CP.
Contacts 5 CP each Resourceful allies, superhero teams, government agencies, and personal confidants.
Extended CP & Tier Block with Breakdown Pop-up: The vitals row features a unified Combined Point-Buy & Tier Block that extends into the space above it to align with the Health and Karma chips. The block displays the active starting Tier Name across the top (e.g., ⚡ Tier: Established Hero / Mutant), the live CP Used meter in the middle (📊 CP Used: 48 / 550 (502 left) [Breakdown ▾]), and the Budget readout at the bottom (Budget: 400 CP [±0%] [⚡ Set Tier & Form]). Clicking this combined block opens the Character Point Breakdown & Budget Adjuster pop-up dialog. The hero's physical Form type (e.g., Form: Mutant) is located in the top bar directly following the character's name.

CP Breakdown Pop-up & Starting CP Budget Slider (-25% to +50%)

The Character Point Breakdown dialog provides comprehensive accounting visibility into your character's resource spending:

  • Itemized Category Breakdown: See exact points spent across Abilities, Powers, Talents, Contacts, and Resources in a clear summary table with spent totals.
  • Visual Progress Meter: A real-time progress bar shows capacity utilization and turns warning-red if your build exceeds available CP.
  • Starting CP Budget Slider in Creation Wizard: The starting CP adjustment slider is located exclusively in the New Character Creation Setup dialog. Scale your starting CP budget from -25% up to +50% (in discrete increments of 25%: -25%, 0%, +25%, +50%) relative to your selected tier's base budget.
  • Resetting Starting Budget: To adjust or reset your character's starting budget after creation, start a new character or roll back to the first character save point in Revision History. The first save point occurs immediately after the hero name, CP allotment, and physical form are chosen.

📊 4. FASERIP Abilities, Vitals & Combat Maneuvers

Main Stats

The Main Stats & Actions Tab provides command over your character's primary attributes and active vitals:

  • The 7 Primary Abilities: Fighting (F), Agility (A), Strength (S), Endurance (E), Reason (R), Intuition (I), and Psyche (P).
  • Column Shift Steppers: Adjust temporary combat modifiers (+1 CS, -2 CS) for environmental hazards, spells, or tactical positioning.
  • Live Health & Karma Trackers: Dedicated rapid-click and accelerating stepper buttons (+1, +5, +10) let you adjust vitals during fast-paced combat rounds. Includes full recovery and quick-heal buttons.
  • Karma Modes: Switch between Standard TSR, CMF Option, and House Rule pool caps.

Calculated Combat & Defense Table

Every character automatically calculates their exact damage ratings, attack ability columns, and defense maneuvers:

Maneuver Governing Ability Damage / Effect Resolution
Blunt Attacks (Punches / Clubs) Fighting (or Agility for thrown) Inflicts Strength rank damage; checks for Stun/Slam on Yellow/Red.
Edged Attacks (Swords / Claws) Fighting Inflicts weapon or Strength damage; checks for Kill/Stun.
Shooting Attacks Agility Inflicts weapon damage rank; checks for Bullseye on Red.
Dodging & Evading Agility Applies negative column shifts to enemy attack rolls.
Blocking Endurance / Shield Material Absorbs incoming blunt or physical damage equal to rank.

🎲 5. Universal Action Table Roller & FEAT Resolution

Dice Roller

The integrated Universal Action Table Dice Roller automates FEAT resolution according to official TSR/CMF rules. You can trigger rolls from any ability card, combat maneuver row, or open the roller independently.

  • d100 Engine: True random roll generation with animated visual feedback.
  • Dynamic Color Band Matching: Instantly evaluates the roll against the active rank column:
    • Dark Blue: Fumble / Blunder / Weapon Mishap (CMF mode).
    • White: Failure.
    • Green: Standard Success.
    • Yellow: Remarkable Success (special effects trigger).
    • Red: Spectacular Success (maximum impact / critical triumph).
  • Column Shift Steppers: Apply temporary buffs or penalties (-3 to +3 CS and custom) with real-time recalculation of percentile thresholds.
  • Karma Spending Stepper: Spend available character Karma point-by-point to adjust the roll upward into the next color band!
  • Pop-out Multi-Window Mode: Click the ↗ Pop Out button to detach the roller into an independent browser window for dual-monitor or tablet tabletop setups.

Powers Tab

The Powers Tab contains the complete superpower library drawn directly from the Ultimate Powers Book (UPB) and the Advanced Set Player's Book:

  • Power Options & Sub-Powers: Many powers (e.g., Elemental Control, Teleportation, Power Simulation) feature configurable variants and sub-powers.

🔬 7. Machines of Doom — Advanced Invention Lab

Invention Lab

The Invention Lab Tab implements the official TSR Advanced Set Machines of Doom invention rules with complete fidelity. Creators can design custom gadgets, mystical artifacts, vehicles, armor, or reverse-engineer rulebook equipment:

The 3-Phase Invention Workflow

  1. Phase 1: Blueprint Design FEAT — The inventor rolls Reason (plus applicable scientific/mystical talents) against the project's target complexity rank. Success drafts a functional blueprint!
  2. Phase 2: Resource Procurement FEAT — The creator rolls Resources against the raw material rank. Success acquires all necessary exotic alloys, arcane reagents, and microcircuits.
  3. Phase 3: Workshop Assembly FEAT — The creator rolls Reason in their workshop over the calculated build duration (in days/weeks). Success produces the completed device!

Invention Source Types: Tech vs. Magic

Toggle between Tech Invention and Magic / Mystical Artifact. The interface dynamically updates terminology, hardware boosts, resource components, and category options:

  • Tech Devices: Weapons, Armor, Vehicles, Sensors, Exoskeletons, and Consumable (gadget, ammo, etc.).
  • Magic Inventions: Talismans, Amulets, Enchanted Weapons, Mystic Armor, and Consumable (rune, potion, etc).

Hardware Boosts & Limitations

Customize your device with over 10 mechanical modifiers:
• Boosts: Expanded Capability (+1 Power), Overload Surge, Remote Control, Concealed Chassis.
• Limitations: Fragile Chassis, Fuel/Power Dependency, Burnout Chance, Feedback Jolt, Finite Charges.

Reverse-Engineering Rulebook Equipment

Select any prebuilt equipment from the official rulebooks in Section 2. The engine instantly computes its raw material procurement intensity, blueprint design difficulty, and workshop build time. With one click, you can reverse-engineer it directly into your Mastered Schematics Archive!

Mastered Schematics Benefit: Any device previously built or successfully reverse-engineered is stored in your character's Known Blueprints Archive. Building from a known blueprint automatically bypasses the Phase 1 Blueprint Design FEAT!

🎒 8. Equipment Armory, Prebuilt Store & Procurement

Equipment

The Equipment Tab equips your hero with standard, military, and exotic gear from published TSR sourcebooks:

  • Prebuilt Equipment Store: Browse hundreds of catalog items divided into Weapons (Guns, Blades, Blunt), Armor & Vests, Electronics & Sensors, Vehicles, Survival Gear, and Special Materials.
  • Automated Procurement Rolls: Click "Procure" on any store item. The modal compares the item's Cost Rank against your hero's Resources rank, displaying Universal Table thresholds and rolling a procurement FEAT.
  • Equipped Status & Encumbrance: Toggle equipped/unequipped status. Equipped weapons automatically register on your Main Stats combat attack table.
  • Custom Gear Builder: Create bespoke weapons, armor, or utility items with custom damage ranks, range brackets, and rules text.

🥋 9. Talents, Contacts & Character Advancement

Talents & Contacts

Heroes are defined as much by their mortal skills and relationships as their superpowers:

  • Talents Catalog: Organized by category (Fighting Masteries, Martial Arts, Weapon Skills, Professional / Vocational, Scientific Specialties, Occult, and Other).
  • Inline Specialization: For talents with choices (e.g., Weapons Specialist or Scientific Specialty), enter your custom focus directly inline.
  • Contacts Manager: Maintain your hero's rolodex of trusted allies, superhero groups, law enforcement contacts, and informant networks.
  • Karma-Driven Character Advancement: Click 📈 Advancement in the top header. The modal implements official TSR rules for spending earned Karma to permanently raise primary ability ranks, acquire new powers, or learn additional talents.

📖 10. Rules Cheat Sheet & Reference Suite

Cheat Sheet

Click 📖 Cheat Sheet in the top header to open a multi-tab quick-reference console designed for instantaneous tabletop lookups during live play:

  • Combat Maneuvers Tab: Full rules text, trigger requirements, and consequences for Charging, Escaping, Grappling, Dodging, Evading, Blocking, and Catching.
  • Movement Tab: Canonical Ground and Flight speed charts showing miles-per-hour and tactical areas-per-round across all ranks. Dynamically toggles between CMF (21 ranks) and Standard (15/17 ranks).
  • Action Table Matrix Tab: The complete Universal Action Table matrix showing exact percentile thresholds for every rank.
  • Material Strengths Tab: Comprehensive list of materials from cloth and glass to vibrant vibranium and adamantium. Synchronized with active ruleset mode.
  • Area Division Rules: Quick reference for standard 132-foot areas, 33-foot quadrants, six 22-foot subareas, or eight 16.5-foot tactical sub-grids.
  • Persistent Multi-Window Pop-out: Detach the Cheat Sheet into an independent floating window. Enable Remember Cheat Sheet Pop-out Across Sessions in Preferences to automatically restore the window on startup!

📁 11. File Management, Themes & Preferences

File Operations

Manage your character archives and tailor the application interface to your preferences via 📁 File / Options ▾:

  • Save Character (.msh): Exports your complete hero sheet, powers, inventions, known blueprints, equipped gear, and history log to a portable .msh JSON file. Defaults to your system Documents folder or last saved location.
  • Open Character (.msh): Imports any saved hero file with full backward compatibility and automated schema migration. Automatically defaults to your last save location.
  • Set Load/Save Folder: Select File / Options ▾ → Set Load/Save Folder... to configure your active directory. Defaults to your system Documents folder in Windows (%USERPROFILE%\Documents), macOS, and Linux. You can browse your local file tree to select any custom folder, and the application will offer to copy or move all known character files to your chosen location. Includes a Reset to Default Location button with automated character migration.
  • Undo / Redo History Navigation: Use the ⮜ and ⮞ arrows in the top tab bar to step backward or forward through your edits.
  • Visual Color Themes:
    • Slate (Default): High-contrast dark comic theme with Marvel Red and Gold accents.
    • Manilla: Clean, soft light stationery palette with crisp dark typography.
    • Aqua: Radiant oceanic theme featuring cyans, sea greens, and deep navy tones.
  • Touch-Friendly Mode: Enlarges interactive buttons, steppers, and inputs for tablets and touchscreens. The File menu displays an intuitive vibrant green (ON) indicator when active.
  • Sticky Navigation: Pins the hero header and tabs to the top of the screen during scrolling.
  • Automated Updates: Checks the GitHub repository for new program releases with one-click notifications.
  • Embedded Surprise: A hidden secret awaits curious players somewhere in the interface—which can be discovered simply by mousehovering somewhere briefly (see Section 13).

🖨️ 12. Print Preview & PDF Export

Printing & PDF

Select 🖨️ Print Preview & PDF Export... from the 📁 File / Options ▾ menu to generate an authentic, print-optimized character sheet:

  • Clean Page Layout: Automatically paginates abilities, vitals, powers, combat maneuvers, equipment, and talents into crisp, ink-friendly sections.
  • Save as PDF: In the browser print dialog, select "Save as PDF" as your destination printer for a clean digital document to share with your gaming group.
  • Physical Tabletop Ready: Formatted specifically for standard Letter (8.5×11") and A4 printer paper.
